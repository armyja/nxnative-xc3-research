## 4. What this does and does not prove

- It shows the production `reflect` arithmetic behaves exactly as expected under the hypothesis: VS offsets 0x110/0x120/
  0x130 become regs 0/1/2 with `cb_slot == 0` and 16-byte alignment already satisfied, while the PS group stays unresolved
  because its base is deliberately still 0.
- It does **not** prove the real vertex table base or that any of these regs matches the guest's NVN register: the base
  0x110 is still a hypothesis, the NVSD handle↔reg relation is still unmeasured, and report80's three live slots remain
  ambiguous. The library is an experiment artifact; nothing was written to a production profile, and no host was built or
  run against it.
