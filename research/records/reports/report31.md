## 2. Packages and map
`vs_first.bin` (2,744 B) and `ps_first.bin` (2,488 B) are one `BTCDBTCD` record each (0x38 header + code area +
control), i.e. the normal package shape — **not** `main.rodata@`, so `dmsh_build.main_rec` is never involved.
`shader_map.tsv` has exactly two `vs_first.bin/pixel/…` and `ps_first.bin/pixel/…` rows with real source comments
(`first_pair#vs0`, `#ps0`); `shader_pairs.tsv` links the two.

**Evidence level of the pair:** the two `[RED]` lines were adjacent in the log, which is *not* proof that one
`ProgramSetShaders` created them together. The pair is therefore labelled an **offline diagnostic combination**, not
a runtime binding fact.
